DESPACHEFULL v3.2.0 — VALIDAÇÃO CONTROLE DE EXPEDIENTE ADMIN
============================================================

RECURSO
Somente o Admin pode encerrar o expediente de um motoboy.

REGRAS VALIDADAS
- presença diária continua por QR ou lançamento manual do Admin;
- encerramento exige Admin autenticado;
- motivo obrigatório;
- motoboy não possui endpoint nem botão para autoencerrar expediente;
- encerramento bloqueado se houver saída ON_ROAD;
- QR não reabre expediente encerrado;
- presença manual não reabre expediente encerrado;
- saída do motoboy bloqueada após encerramento;
- saída manual do Admin bloqueada após encerramento;
- Dashboard exclui encerrados de Motoboys ativos e Disponíveis;
- presença histórica permanece salva no relatório;
- relatório diário inclui entrada, encerramento e duração;
- CSV inclui dados do encerramento;
- auditoria registra ATTENDANCE_ADMIN_CHECKOUT.

BANCO
- checked_out_at TIMESTAMPTZ
- checked_out_by INTEGER
- checkout_reason TEXT
- ALTER TABLE com IF NOT EXISTS para atualização segura.
