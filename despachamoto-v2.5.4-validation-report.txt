DespachaMoto v2.5.4 — validação de sessão expirada
==================================================

RECURSO
Retorno automático ao login quando uma sessão autenticada expira.

COMPORTAMENTO
- resposta HTTP 401 em uma sessão previamente autenticada dispara redirecionamento ao login;
- mensagem exibida: "Sua sessão expirou. Entre novamente para continuar.";
- usuário é reapresentado no campo de login quando disponível;
- senha não é armazenada;
- heartbeat de 20 segundos detecta sessão expirada mesmo sem clique do usuário;
- helper API, saída do motoboy, fila offline e saída manual do Admin estão cobertos;
- backend retorna code SESSION_EXPIRED quando a sessão não existe.
